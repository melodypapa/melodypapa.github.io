title: "应用接口（Application Interfaces）"

AUTOSAR 为各汽车域（底盘、动力总成、车身与舒适、乘员与行人安全、HMI/多媒体/远程信息处理等）定义了统一的应用接口（Application Interface），以实现跨供应商软件组件的可移植性与互操作性。本节收录应用接口域的说明性文档（EXP）中文翻译：各域接口说明，以及 ADAS 车辆运动控制接口与应用接口用户指南。
