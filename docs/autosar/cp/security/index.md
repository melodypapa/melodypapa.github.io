---
title: "网络安全（Security）"
---

**AUTOSAR** 网络安全（**Security**）相关的基础软件模块：防火墙基于预定义规则对网络流量进行检查与过滤；入侵检测系统管理器（**IdsM**）接收 **IDS** 传感器报告的安全事件，经可配置过滤链鉴定后向 **IdsR** / **Dem**（**Sem**）接收器传播或持久化。二者共同构成车内的纵深防御能力。
