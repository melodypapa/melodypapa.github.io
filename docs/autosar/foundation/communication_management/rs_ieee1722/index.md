## 1. 文档范围

本文档旨在为 **AUTOSAR** 中对桥接局域网内时间敏感应用的 **IEEE** 标准化传输协议（见 [1, IEEE Std 1722-2016]）的支持定义功能需求与非功能需求。

### 3.2. 定义

#### 3.2.1. 以太网分组（**Ethernet packet**）

定义：「**以太网分组**」是由 [5, IEEE Std 802.3-2022] 定义的线上格式，包含以下部分：前导码（Preamble，7 字节）、SFD（帧起始定界符，1 字节）、以太网帧（最长 2000 字节）。

#### 3.2.2. 以太网帧（**Ethernet frame**）

定义：「**以太网帧**」是由 [5, IEEE Std 802.3-2022] 定义的线上格式，包含以下部分：**MAC** 目的地址字段（6 字节）、**MAC** 源地址字段（6 字节）、类型字段（2 字节）、**MAC** 客户数据字段（包含可选的 Q-Tag（4 字节））（最长 1982 字节）、可选的 PAD（填充字节）、FCS（帧校验序列，4 字节）。

#### 3.2.3. 流（**Stream**）

定义：「**流**」表示由相似的帧属性（例如 **MAC** 源地址）分组在一起的多个以太网帧。

#### 3.2.4. IEEE1722 流（**IEEE1722 stream**）

定义：「**IEEE1722 流**」表示 EtherType 设置为 **AVTP** EtherType（0x22F0）的多个以太网帧（见 [1, IEEE Std 1722-2016]），其携带 **IEEE1722** 规定的 **AVTP** 报头以及一个 **AVTP** 流数据子类型（例如 **AAF**（**AVTP Audio Format**））。

#### 3.2.5. 流数据提供者（**Stream data producer**）

定义：「**流数据提供者**」表示以太网网络中（连续地）产生数据的终端节点。该数据经由一个流发送，并由一个或多个终端节点（**流数据消费者**）接收。

**注意：** 术语「**talker**」与「**流数据提供者**」同义。

#### 3.2.6. 流数据消费者（**Stream data consumer**）

定义：「**流数据消费者**」表示以太网网络中（连续地）消费数据的终端节点。该数据经由流接收。

**注意：** 术语「**listener**」与「**流数据消费者**」同义。

#### 3.2.7. AVTP 呈现时间（**AVTP presentation time**）

定义：「**AVTP 呈现时间**」由 [1, IEEE 1722-2016] 定义，表示 **AVTPDU** 载荷中的指定数据被传递给流数据消费者的时间敏感应用时的 **gPTP** 时间。报头格式为 AVTPDU-common-stream-header 的 **AVTPDU** 报头按照 [1, IEEE 1722-2016] 以 `avtp_timestamp` 携带该呈现时间。**AVTP** 呈现时间按 `TavtpPresentationTime` = `TcurrentGlobalTime` + `TmaxTransitTime` 计算。请注意：呈现时间不包含接收方时间敏感应用的格式转换时间和处理时间（见 [1, IEEE 1722-2016] 图 6「Figure 6 - AVTP Timing Reference Planes」）。

#### 3.2.8. 最大传输时间（**Max transit time**）

定义：「**最大传输时间**」由 [1, IEEE 1722-2016] 定义，表示从流数据提供者的数据进入其发送队列起，经网络通过一个 **IEEE1722** 流传输，到该数据从接收方流数据消费者的接收队列转发给时间敏感应用为止的最大可接受延迟。

#### 3.2.9. 媒体时钟（**Media clock**）

定义：「**媒体时钟**」由 [1, IEEE 1722-2016] 定义，表示一个产生速率的实体（例如具有恒定速率（如 48kHz）的精确硬件时钟）。媒体时钟由**媒体时钟提供者**承载。

#### 3.2.10. 媒体时钟提供者（**Media clock provider**）

定义：「**媒体时钟提供者**」是网络中承载一个媒体时钟的终端节点。媒体时钟提供者向一个或多个**媒体时钟消费者**发送 **IEEE1722** 流。该 **IEEE1722** 流的子类型为 **CRF**（时钟参考格式），并包含若干与媒体时钟速率相关的呈现时间戳。

#### 3.2.11. 媒体时钟消费者（**Media clock consumer**）

定义：「**媒体时钟消费者**」是网络中从媒体时钟提供者接收子类型为 **CRF**（时钟参考格式）的 **IEEE1722** 流的终端节点。媒体时钟消费者基于从媒体时钟提供者接收到的封装数据执行其媒体时钟恢复（例如 **PLL**）。

## 4. 需求规格

本章描述驱动 **FO\_RS\_IEEE1722** 定义工作的全部需求。

### 4.1. 功能概述

**IEEE** 为桥接局域网内的时间敏感应用规定了一种传输协议（见 [1, IEEE Std 1722-2016]）。**IEEE1722** 流在流数据提供者与一个或多个流数据消费者之间传输数据。**IEEE1722** 流尤其携带所谓的「**AVTP 呈现时间**」。**AVTP** 呈现时间使得在局域网内多个经由 **IEEE1722** 流接收数据的终端节点上同步处理数据成为可能。**IEEE1722** 传输协议支持多种 **AVTP** 子类型以覆盖不同的用例，例如：

- 音视频流传输
- 分发所谓媒体时钟所产生的时钟速率
- 封装总线帧（例如 **CAN** 帧、**LIN** 帧）并经由 **IEEE1722** 流跨网络传输

本规范包含在经典平台与自适应平台中支持 **IEEE1722** 流处理的需求。
