## 1. 文档范围

本文档规定对 **AUTOSAR** 网络管理（**Network Management**）的需求。

这些需求适用于以下功能实体：

- 协调特定 Nm 集群（**Nm-cluster**）的网络管理
- 特定总线的网络管理总线特定部分
- Nm 集群之间网络管理的网关与互操作性

Nm 所适用的通信系统必须支持「总线休眠（**bus sleep**）」模式。这意味着通信系统的收发器可以切换到低功耗模式，并且可以通过（特定的）总线流量和/或应用再次切换回全功率模式。

## 3. 缩略语和缩写

**Nm**
> 网络管理（**Network Management**）

**PN**
> 部分网络（**Partial Network**）

**PNI**
> 部分网络信息（**Partial Network Information**）

**Nm Message**
> 指总线上传输的载荷。它包含用户数据（**User Data**）以及控制位向量（**Control Bit Vector**），并可以包含源节点标识符（**Source Node Identifier**）。

**Nm Node**
> 连接到一个或多个 Nm 集群的 **ECU**（电子控制单元）。

**Nm cluster**
> 使用 Nm 算法协调的 Nm 节点集合。

**Nm instance**
> 一个 Nm 实例表示一个 Nm 节点内部一个 Nm 集群的当前状态。

上文各表未提供的缩略语/缩写和术语包含在 **AUTOSAR** 术语表 [\[2\]](#ref-2) 中。

## 4. 用例

表4.1：网络管理的用例（**Use Cases of Network Management**）

| ID | 名称 | 描述 |
| --- | --- | --- |
| 0001 | 同步关闭（**Synchronous Shutdown**） | 如果 Nm 集群中没有通信需求，Nm 协议确保所有 Nm 节点同步进入休眠模式。 |
| 0002 | 子网络同步关闭（**Sub-networks Synchronous Shutdown**） | 支持多个子网络的协调关闭。这可以视为同步关闭用例的扩展，其目标是同步关闭多个 Nm 集群。 |
| 0003 | 保持 Nm 集群唤醒（**Keep Nm Cluster Awake**） | 如果 Nm 集群中至少有一个 Nm 节点需要通信，Nm 协议确保所有需要的 Nm 节点保持唤醒。 |
| 0004 | 部分网络（**Partial Network**） | 通过定义通信/功能域来支持部分网络，从而在某些条件下不需要某些 **ECU** 所提供的功能时，允许关闭跨多个 **ECU** 的网络通信。其他 **ECU** 可以继续在相同的总线通道上通信。此外，使用 Nm 消息在参与的 **ECU** 之间传递部分网络集群的请求/释放信息。 |
| 0005 | 被动模式（**Passive Mode**） | 配置为被动节点（**Passive node**）的 Nm 节点不能发起 Nm 集群的启动，但如果任何其他节点发起启动，它能够被唤醒。这消除了不必要的通信并减少了总线和缓冲区开销。允许关闭由集群节点的一个子集控制，使得只有容错节点控制关闭成为可能。 |
| 0006 | 部分网络网关（**Partial Network Gateway**） | 由于部分网络跨越多条总线，网络管理协议定义了部分网络信息应如何在这些总线之间网关转发，即应能够向子网络转发请求/释放信息，从而允许网关 **ECU** 代表原始的部分网络请求方 **ECU** 采取行动。 |
| 0007 | FlexRay Nm（**FlexRay Nm**） | 支持 **FlexRay** 总线的特定特性及其 **HW** Nm 向量支持。网络管理协议应支持 **FlexRay** 总线的替代方案，其中可以使用 **FlexRay** 协议规范的网络管理向量（**Network Management Vector**）。 |

上文各表未提供的缩略语/缩写和术语包含在 **AUTOSAR** 术语表 [\[2\]](#ref-2) 中。

#### 5.1.3. 正常运行

**Nm 应适用于 AUTOSAR 范围内且支持总线休眠模式的不同类型通信系统**

| 描述 | 每个受支持协议的网络管理机制应使用有限数量的预定义 Nm 状态和 Nm 转换来实现。触发状态间转换的事件以及在这些转换上采取的动作可以是协议特定的。每种协议都应支持总线休眠模式。Nm 应既可在异步通信系统（例如 **CAN**）上执行，也可在同步通信系统（例如 **FlexRay**）上执行，还可在这两种系统之上的、**AUTOSAR** 范围内的任何其他类型通信系统上执行。 |
