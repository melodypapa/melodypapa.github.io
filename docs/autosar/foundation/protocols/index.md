**AUTOSAR** 基础标准（**Foundation**）R23-11「协议（**Protocols**）」类别的中文翻译笔记。跨平台的协议规范（**PRS**）及其需求：**SOME/IP** 与 **SOME/IP** 服务发现、**E2E**、**SecOC**、网络管理、时间同步、日志与跟踪、入侵检测系统、**V2X** 远程访问层，以及 **DDS** 与 **IPsec** 的需求规范。
