## 1. 文档范围

本文档规定面向 IP 的可扩展服务导向中间件（**SOME/IP**）协议的需求——一种汽车/嵌入式协议及其底层序列化/线上格式，可用于请求/响应通信和基于事件的通信。

规定「又一种 RPC 机制」而非使用既有基础设施/技术的基本动机，是获得一种能够：

- 在尽可能多的用例和通信伙伴之间兼容
- 提供汽车用例所需的特性
- 从小型平台可扩展到大型平台
- 可实现于不同操作系统（即 **AUTOSAR**、**GENIVI** 和 **OSEK**）甚至无操作系统的嵌入式设备之上

的技术。

## 2. 缩略语和缩写

以下收录与 **SOME/IP** 规范相关、且未被 [2, AUTOSAR glossary] 收录的缩略语和缩写。

**Event**
> 事件（**Event**）：仅在变化时或周期性调用的单向数据传输，从数据的生产者发送给消费者。

**Eventgroup**
> 事件组（**Eventgroup**）：服务内的事件以及字段的通知事件的逻辑分组，以允许订阅。

**Field**
> 字段（**Field**）：字段表示一种状态，因此在任意时刻都持有一个有效值，getter、setter 和 notifier 作用于其上。

**Getter**
> 读取器（**Getter**）：允许对字段进行读访问的请求/响应调用。

**Method**
> 方法（**Method**）：被调用/调用的方法、过程、函数或子例程。

**Notification Event**
> 通知事件（**Notification Event**）：字段的通知器（**Notifier**）发出的事件消息。

**Notifier**
> 通知器（**Notifier**）：在字段的值发生变化时，发送带有新值的事件消息。

**Remote Procedure Call (RPC)**
> 远程过程调用（**RPC**）：从一个 **ECU** 到另一个 **ECU**、使用消息传输的方法调用。

**Service**
> 服务（**Service**）：零个或多个方法、零个或多个事件以及零个或多个字段的逻辑组合。

**Service Instance**
> 服务实例（**Service Instance**）：服务的实现，可以在车辆中出现多次，也可以在一个 **ECU** 上出现多次。

**Setter**
> 写入器（**Setter**）：允许对字段进行写访问的请求/响应调用。

**SOME/IP**
> 面向 IP 的可扩展服务导向中间件（**Scalable service-Oriented MiddlewarE over IP**）。

**TCP**
> 传输控制协议（**Transmission Control Protocol**）。

**UDP**
> 用户数据报协议（**User Datagram Protocol**）。

**Union**
> 联合（**Union**）：动态采用不同数据类型的数据结构。

| 描述 | **SOME/IP** 协议应提供大数据分段传输的支持。发送方应能够将一条大消息拆分为多个较小的分段。这些分段被传输给接收方。接收方应能够重组出原始消息。 |

| 用例 | 大于 65KB 数据的时间关键传输。 |
| 适用平台 | **FO** |
| 依赖项 | - |
| 支撑材料 | - |
