title: "全局时间（Global Time）"

**AUTOSAR** 全局时间（**Global Time**）相关的规范笔记：包括提供同步时基的同步时基管理器（**Synchronized Time-Base Manager**，**StbM**），以及各总线上与 **StbM** 配合完成时间同步的时间同步提供者模块——**CAN** 时间同步（**CanTSyn**）、**Ethernet** 时间同步（**EthTSyn**）和 **FlexRay** 时间同步（**FrTSyn**）。
