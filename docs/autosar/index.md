**AUTOSAR**（AUTomotive Open System ARchitecture）标准 R23-11 的中文翻译笔记，按标准所属的平台分为两部分：**Classic Platform**（**CP**，经典平台）收录各基础软件模块（**BSW**）的软件规范（**SWS**）、说明文档（**EXP**）与模板规范（**TPS**）的翻译；**Foundation**（基础标准）收录 **Classic Platform** 与 **Adaptive Platform** 共用的跨平台规范——需求规范（**RS**）、协议规范（**PRS**）、模板规范（**TPS**）与技术报告（**TR**）。两部分共用同一份[术语表](glossary.md)。

## 文章

* [CP AUTOSAR（经典平台）](cp/index.md) — 通信、全局时间、加密、诊断、通用、I/O、MCAL、存储、方法论与模板、模式管理、系统服务、功能安全、RTE、应用接口、SW 架构、库与模板
* [基础标准（Foundation）](foundation/index.md) — 通用、通信管理、诊断、健康监控、方法论与模板、协议、发布文档、功能安全、信息安全、系统服务
