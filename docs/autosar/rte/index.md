**AUTOSAR** 运行时环境（**Runtime Environment**，**RTE**）与基础软件调度器（**Basic Software Scheduler**，**SchM**）相关文章，均译自《**AUTOSAR CP SWS RTE**》（R23-11）。**RTE** 是应用层软件组件与基础软件之间的粘合层；**SchM** 与 **RTE** 的调度部分交织在一起，由 **RTE** 生成器一并生成，为基础软件模块提供调度、独占区与模式管理 **API**。

## 文章

* [AUTOSAR RTE（运行时环境）](rte/index.md) —— SWS RTE 全文译文（含基础软件调度器参考）
* [AUTOSAR SchM（基础软件调度器）](schm/index.md) —— SWS RTE 第 6 章 **Basic Software Scheduler Reference** 的独立译文，另含 SchM 理论章节（与基础软件模块的关系、实现相关方面、模式切换顺序、初始化/终结与生成过程）
