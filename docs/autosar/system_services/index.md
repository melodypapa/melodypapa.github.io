title: "系统服务（System Services）"

**AUTOSAR** 系统服务（**System Services**）层的基础软件模块笔记：系统服务位于服务层，为应用软件与其他基础软件模块提供与硬件无关的基础服务，包括提供任务调度、中断、报警与保护机制的操作系统（**Os**）、按功能禁止条件控制功能可用性的功能禁止管理器（**FiM**），以及提供基于 **Os** 计数器的时间测量与超时服务的时间服务（**Time Service**）。
