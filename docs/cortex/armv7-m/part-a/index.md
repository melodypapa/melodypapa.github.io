Part A 描述本架构的应用程序级视图，共 7 章（A1–A7）。下列清单按手册章序给出每章的翻译状态。

## 1. 章节

1. [简介（Introduction）](introduction/index.md) — Chapter A1，已译。介绍 **Armv7** 架构、它定义的架构配置文件，以及本手册所定义的 **Armv7-M** 配置文件与架构扩展。
2. [应用程序级程序员模型（Application Level Programmers' Model）](application_level_model/index.md) — Chapter A2，已译。给出 **Armv7-M** 程序员模型的应用级视图，包括数据类型与运算、寄存器与执行状态、异常与故障的含义、可选的浮点扩展与协处理器支持。
3. [ARM 架构的内存模式（Arm Architecture Memory Model）](arm_architecture_memory_mode/index.md) — Chapter A3，已译。给出 **Armv7-M** 内存模型的应用程序级视图，包括 Arm 内存属性与内存排序模型。
4. [Armv7-M 指令集（The Armv7-M Instruction Set）](instruction_set/index.md) — Chapter A4，已译。描述 **Armv7-M** 的 **Thumb** 指令集：互工作支持、**UAL** 汇编语法、存储器访问指令、通用数据处理指令、乘除与 **DSP** 扩展、饱和指令、分支与控制指令、杂项指令、协处理器指令，以及浮点加载/存储、寄存器传送与数据处理指令。
5. [Thumb 指令集编码（Thumb Instruction Set Encoding）](thumb_instruction_set_encoding/index.md) — Chapter A5，已译。描述 Thumb 指令集的编码。
6. [浮点指令集编码（Floating-point Instruction Set Encoding）](fp_instruction_set_encoding/index.md) — Chapter A6，已译。描述 Thumb 指令集的浮点编码扩展；可选的 **Armv7-M** 浮点架构扩展提供这些附加指令。
7. [指令详情（Instruction Details）](instruction_details/index.md) — Chapter A7，已译。按字母顺序给出每条 Thumb 指令的编码、汇编语法、操作伪代码与异常信息；A7.1–A7.6 与全部 263 条指令（7.1–7.263）均已译出。

已译 7 章（A1、A2、A3、A4、A5、A6、A7）。
