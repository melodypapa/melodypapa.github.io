Part A 描述本架构的应用程序级视图。它包含以下章节：

## 1. 章节

1. [ARM 架构的内存模式（Arm Architecture Memory Model）](../arm_architecture_memory_mode/index.md) — Chapter A3，给出 **Armv7-M** 内存模型的应用程序级视图，包括 Arm 内存属性与内存排序模型。
2. [Thumb 指令集编码（Thumb Instruction Set Encoding）](../thumb_instruction_set_encoding/index.md) — Chapter A5，描述 Thumb 指令集的编码。
3. [浮点指令集编码（Floating-point Instruction Set Encoding）](../fp_instruction_set_encoding/index.md) — Chapter A6，描述 Thumb 指令集的浮点指令集编码扩展。可选的 **Armv7-M** 浮点架构扩展提供这些附加指令。
4. [Cortex-M7 指令集](../../m7-trm/instruction_set/index.md) — Chapter A4，描述 **Armv7-M** Thumb 指令集。该章与 Cortex-M7 TRM 的实现章节合为一篇，归在 Cortex-M7 TRM 专题。

Chapter A1《简介》（Introduction）、Chapter A2《应用程序级程序员模型》（Application Level Programmers' Model）与 Chapter A7《指令详情》（Instruction Details）尚未翻译，见 `sync-todo/ARMv7-M.md` 队列。
