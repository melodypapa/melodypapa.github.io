## 1. 关于 Armv7 架构与架构配置文件

**Armv7** 以一组架构配置文件（architecture profile）的方式给出文档。这些配置文件的定义如下：

**Armv7-A**
> 支持 **Arm** 和 **Thumb** 指令集，且内存管理模型要求虚拟地址支持的系统所对应的应用配置文件。

**Armv7-R**
> 支持 **Arm** 和 **Thumb** 指令集，且内存管理模型仅要求物理地址支持的实时配置文件。

**Armv7-M**
> 仅支持 **Thumb** 指令集，且实现的整体尺寸与确定性运行比绝对性能更重要的系统所对应的微控制器配置文件。

虽然架构配置文件是随 **Armv7** 的开发正式引入的，但 A-profile 与 R-profile 在更早的版本中已经隐含存在，分别与虚拟内存系统架构（Virtual Memory System Architecture, VMSA）和保护内存系统架构（Protected Memory System Architecture, PMSA）相关联。

## 2. Armv7-M 架构配置文件

Arm 架构经过若干次重大修订演进至今，已支持覆盖广泛性能点区间的各类实现，年产量超过十亿颗。最新版本 **Armv7** 通过定义一组架构配置文件、使架构针对不同市场需求进行裁剪，从而正式承认了这种多样性。一个关键因素是应用级在所有配置文件之间保持一致，而大部分差异位于系统级。

Thumb-2 技术在 Armv6T2 中的引入为 **Arm** 与 **Thumb** 指令集带来了平衡，也使 Arm 架构有机会扩展到新的市场，尤其是微控制器市场。为最大限度地利用这一机会，Arm 推出了面向微控制器实现的 **Armv7-M** 架构配置文件，以补充其在高性能与实时嵌入式市场的优势。**Armv7-M** 是仅支持 **Thumb** 的配置文件，并带有全新的系统级程序员模型。

**Armv7-M** 实现的关键准则如下：

* 支持具备业界领先功耗、性能与面积约束的实现：
  * 为简单流水线设计提供机会，从而在广泛的市场与应用中提供领先的系统性能水平。
* 高度确定性的运行：
  * 单周期或低周期数执行。
  * 中断延迟最小，流水线短。
  * 能够无缓存运行。
* 优秀的 C/C++ 目标。这与 Arm 在该领域的编程标准一致：
  * 异常处理程序是标准 C/C++ 函数，使用标准调用约定进入。
* 面向深度嵌入式系统设计：
  * 引脚数少的器件。
  * 为 Arm 架构带来新的入门级机会。
* 为事件驱动系统提供调试与软件剖析支持。

本手册专门针对 **Armv7-M** 配置文件。

## 3. 架构扩展

本手册描述 **Armv7-M** 架构配置文件的以下扩展：

**DSP extension**
> 该可选扩展为 **Armv7-M** **Thumb** 指令集增加 Arm 数字信号处理（Digital Signal Processing, DSP）指令。这些指令包括饱和指令与无符号单指令多数据（Single Instruction Multiple Data, SIMD）指令。
>
> 包含 DSP 扩展的 **Armv7-M** 实现称为 **Armv7E-M** 实现，Chapter A7《指令详情》将这些新增指令标识为 **Armv7E-M** 指令。

**Floating-point Extension**
> 该可选扩展为 **Armv7-M** **Thumb** 指令集增加浮点指令。浮点扩展有两个可用版本：
>
> * **FPv4-SP**：这是为 **Armv7-A** 与 **Armv7-R** 架构配置文件定义的 VFPv4-D16 扩展的单精度实现。
> * **FPv5**：该扩展增加对双精度计算的可选支持，并提供附加指令。

**注意：** 在 **Armv7-A** 与 **Armv7-R** 架构配置文件中，可选浮点扩展称为 VFP 扩展。该名称是历史名称，而对应 **Armv7-M** 配置文件扩展的缩写是 FP 扩展。**Armv7-M** FP 扩展引入的指令与 **Armv7-A** 和 **Armv7-R** 配置文件中等效的单精度浮点指令完全相同，并使用相同的指令助记符。这些助记符以 V 开头。

基于为 **Armv7-A** 与 **Armv7-R** 架构配置文件定义的 VFP 实现选项，**Armv7-M** 浮点扩展的特征如表 A1-1 所示。某些软件工具可能需要这些特征描述。

| 扩展 | 仅单精度 | 单精度和双精度 |
| --- | --- | --- |
| FPv4-SP | FPv4-SP-D16-M | 不适用 |
| FPv5 | FPv5-SP-D16-M | FPv5-D16-M |
