本专题收录第 C2 章《指令规范》中 C2.4「按字母顺序的指令列表」的中文翻译，按指令助记符的首字母分段。每条指令依次给出用途说明、各编码（T1、T2 …）的位域图与汇编语法、解码与操作伪代码、汇编符号说明，以及受限行为和数据独立时序行为。指令助记符、字段名、寄存器名、伪代码与汇编语法保持原样，说明文字译为中文。

手册原文共 493 条指令（C2.4.1–C2.4.493，印刷 528–1440），后续字母段随翻译进度补充。
