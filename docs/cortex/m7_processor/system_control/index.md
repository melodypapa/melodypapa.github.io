本章介绍用于编程处理器的寄存器。

## 1. 关于系统控制

本章介绍用于控制处理器操作的寄存器。这包括位于以下空间的寄存器：

* 系统控制空间（**System Control Space**）。
* 访问控制空间（**Access Control Space**）。
* 标识空间（**Identification Space**）。
* 缓存维护空间（**Cache Maintenance Space**）。

## 3. 寄存器描述

本节介绍以下实现特定于本处理器的系统控制寄存器：

* 辅助控制寄存器。
* CPUID 基址寄存器。
* 缓存级别 ID 寄存器。
* 缓存大小 ID 寄存器。
* 缓存大小选择寄存器。
* 指令与数据紧密耦合内存控制寄存器。
* AHBP 控制寄存器。
* L1 缓存控制寄存器。
* 辅助总线故障状态寄存器。
* 指令错误 bank 寄存器 0-1。
* 数据错误 bank 寄存器 0-1。
* AHB 从控制寄存器。
